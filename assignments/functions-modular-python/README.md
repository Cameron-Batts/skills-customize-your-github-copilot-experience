# 📘 Assignment: Functions and Modular Python

## 🎯 Objective

Practice writing reusable Python functions and organizing code into modules so students can build cleaner, more maintainable programs.

## 📝 Tasks

### 🛠️ Define Reusable Functions

#### Description
Write functions that perform specific tasks with inputs and outputs.

#### Requirements
Completed program should:

- Define at least two reusable functions in `helpers.py`
- Use parameters and return values instead of global variables
- Keep logic inside functions and avoid repeating code

### 🛠️ Create a Module

#### Description
Put the helper functions into a separate module and import them into the main program.

#### Requirements
Completed program should:

- Create `helpers.py` with helper functions
- Import the module or specific functions in `starter-code.py`
- Use the imported functions from the main program

### 🛠️ Build a Simple Program

#### Description
Use the imported helper functions to process input and display results.

#### Requirements
Completed program should:

- Ask the user for information or use sample values
- Call helper functions to perform calculations or formatting
- Print clear, user-facing output
- Keep the main script simple and delegate work to the module
